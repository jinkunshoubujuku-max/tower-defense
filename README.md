# ARCROOT // Isometric Defense

ローグライト × インクリメンタル × タワーディフェンスのブラウザ向けプレイアブル・プロトタイプです。

## 遊び方

1. 右側の **BUILD MATRIX** からタワーを選びます。
2. フィールド上の円形ビルドノードをクリックして配置します。
3. **DEPLOY WAVE** で敵ウェーブを開始します。
4. 敵を倒してレベルを上げ、画面下の **SKILL MATRIX** からビルドを強化します。

## 起動

ビルド工程はありません。任意の静的ファイルサーバーで配信してください。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。
